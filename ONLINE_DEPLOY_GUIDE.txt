AK LOGISTIC & TRANSPORT — ONLINE DEPLOYMENT

Recommended first deployment: Render Web Service + Docker.

1. Create a GitHub repository and upload this package's files.
2. In Render: New → Web Service → connect the GitHub repository.
3. Select Docker runtime (Render can build from the included Dockerfile).
4. Add environment variable:
   ADMIN_PASS = choose a strong password
5. Keep SECRET_KEY generated by Render.
6. Health check path: /health
7. Deploy.
8. Render will provide an HTTPS onrender.com URL.
9. Open that URL in iPad Safari.

IMPORTANT:
- The free Render service can spin down after inactivity.
- This first setup uses SQLite without a persistent disk, so it is suitable for testing/demo.
- For real business data, attach persistent storage or migrate to managed PostgreSQL before production use.
- Telegram is intentionally not connected yet.

Admin username defaults to: admin
Admin password must be set by you in Render.

GitHub is used as the code repository; Render can deploy from a connected Git repository.
